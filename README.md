# ПравоСправка

Готовый статический проект правовой информационной системы для GitHub Pages.

## Запуск

1. Создайте репозиторий на GitHub.
2. Загрузите `index.html`, `style.css`, `app.js`, `laws.json`.
3. Откройте Settings → Pages.
4. В качестве источника выберите ветку `main` и папку `/root`.
5. Сайт будет опубликован как GitHub Pages.

## Как работает база

- `laws.json` — стартовая база документов.
- После открытия сайта документы копируются в `localStorage`.
- Через «Управление» можно создавать и редактировать документы.
- «Экспорт JSON» позволяет получить изменённую базу и заменить `laws.json` в GitHub.
- GitHub Pages не предоставляет серверную базу данных: изменения одного пользователя не становятся общими для всех посетителей.

## Важно

В проекте размещены демонстрационные фрагменты нормативных актов, а не полноценная актуальная юридическая база. Перед использованием в реальной юридической работе тексты и редакции необходимо сверять с официальными источниками законодательства.
